# Adversarial review: embedded terminal and stage backend

Status: closed on 2026-11-01. Generated from the reviewers' actual results and the fix agents' closure notes. Nothing here was run on Windows.

## What was done

After the terminal and the stage backend were built, two reviewers were told to break them and not to edit the code. Both wrote and ran their own attack scripts (kept outside the repo). Two fix agents then closed the findings, re-ran the reviewers' scripts, and added regression tests. The lead re-ran the whole gate afterwards: 2,714 unit tests and 132 end-to-end checks in real Chromium against real daemon processes, with no orphaned PTY hosts left over.

| Reviewer | Checks run | Failing findings | Held up |
|---|---|---|---|
| Terminal attacker | 116 | 3 high, 3 medium, 11 low, 3 info | Ticket model (single use, expiry, terminal and session binding), Origin and Host checks, cwd traversal and symlink escapes, no lane or tool path to the terminal, no keystrokes in logs |
| Stage fuzzer | 156 (about 5 million inputs) | 2 high, 11 medium, 32 low, 9 info | Stage socket auth (28-case matrix and a 30-way race), licence enforcement on every use path, the adult envelope on every live update path, the binary frame decoder never threw |

Neither reviewer found a critical flaw (no unauthenticated or cross-origin command execution, no bypass of stage auth, no way around the adult envelope or licence checks on a live path).

## What remains true after the fixes

- **A process that deliberately daemonises** (setsid plus re-parenting to init, double-fork, systemd-run) can outlive its terminal. Tying it down needs cgroups on Linux or Job Objects on Windows (not built).
- **Same OS user:** anything running in a terminal, as the same user, can read the daemon's secrets file and process environment. This is inherent; the planned upgrade is the OS credential store.
- **A stolen cookie** can still read dashboards and switch terminals OFF, but can no longer start, attach to or switch on a terminal: those need a second proof that is not in the cookie jar (it rides in the fragment of the printed sign-in link).
